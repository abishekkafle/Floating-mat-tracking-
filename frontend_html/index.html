Quick start

  1. Connect a USB webcam.
  2. Adjust Camera index if needed and click Start.
  3. Tune HSV sliders until only the mat is highlighted (inset mask at top-left of the video).
  4. Hold the mat steady and click Set reference (current).
  5. Move the mat; the app shows distance and angle drift (and cm if you entered the mat's side length).
